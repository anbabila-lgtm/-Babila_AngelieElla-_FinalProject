# 🔐 CLI Password Vault Manager

## 📌 Project Description

The CLI Password Vault Manager is a Python command-line application that allows users to securely manage account passwords for different websites and applications.

This system can:
- Save passwords
- Search accounts
- Delete accounts
- Generate strong passwords
- Check password strength

The project demonstrates various Python programming concepts including:
- Object-Oriented Programming (OOP)
- Lists, Tuples, Sets, and Dictionaries
- File Handling and Exception Handling
- User-Defined Functions
- Python Modules and Built-in Functions

---

# ✨ Features

- Add New Password
- View Saved Accounts
- Search Account
- Delete Account
- Generate Strong Password
- Password Strength Checker
- JSON File Storage
- Error Handling for Invalid Inputs

---

# ⚙️ Installation / Setup

1. Download or clone the repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the application:

python src/main.py
